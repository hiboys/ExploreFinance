# 网页工具

## 股票分析工具

### 公允价值 - GuruFocus
```bash
start "" "https://www.gurufocus.cn/stock/{stockCode}/summary"
```
- example：https://www.gurufocus.cn/stock/000001/summary

### 财联社/CLS搜索
```bash
start "" "https://www.cls.cn/searchPage?keyword={keyword}&type=all"
```

### 巨潮资讯（公告搜索）
```bash
start "" "https://www.cninfo.com.cn/new/fulltextSearch?notautosubmit=&keyWord={keyword}"
```

### 杜邦分析（新浪财经）
```bash
start "" "https://vip.stock.finance.sina.com.cn/corp/go.php/vFD_DupontAnalysis/stockid/{stockCode}/displaytype/10.phtml"
```

### 百度FinScope - 股票分析
```bash
start "" "https://finance.baidu.com/stock/ab-{stockCode}"
```

## ETF/指数分析工具

### 红色火箭基本面
```bash
start "" "https://www.etf818.com/red-rocket/indexDetail?securityCode={stockCode}.{market}"
```
- example: https://www.etf818.com/red-rocket/indexDetail?securityCode=000001.SH

### 百度FinScope - 指数分析
```bash
start "" "https://finance.baidu.com/index/ab-{indexCode}"
```

### 百度FinScope - 板块分析
> blockCode是申万行业代码（最新版）
```bash
start "" "https://finance.baidu.com/block/ab-{blockCode}"
```
- example: https://finance.baidu.com/block/ab-650100 (航天装备Ⅱ)

## 基金分析工具

### 晨星网 - 基金详情
```bash
start "" "https://www.morningstar.cn/fund/{fundCode}.html"
```
- example: https://www.morningstar.cn/fund/008302.html (永赢易弘债券A)
- 说明：晨星评级、基金业绩、风险指标、持仓分析等详细数据

### 证监会 - 公募基金信息披露平台
```bash
start "" "http://eid.csrc.gov.cn/fund/disclose/index.html"
```
- 说明：证监会官方公募基金信息披露平台，可查询基金公告、招募说明书、定期报告等法定披露信息

## 市场情绪/拥挤度工具

### 大盘拥挤度（legulegu）
```bash
start "" "https://legulegu.com/stockdata/ashares-congestion"
```

### 北向资金成交额（MacroMicro）
```bash
start "" "https://sc.macromicro.me/series/45792/china-northbound-fund-transaction-total"
```
- 来源：财经M平方
- 说明：追踪沪深港通北向资金每日成交金额与流向

### 美国 SOFR/IOER 利差（MacroMicro）
```bash
start "" "https://www.macromicro.me/charts/141325/us-sofriorb-spread"
```
- 来源：财经M平方
- 说明：美元流动性压力指标，SOFR（有担保隔夜融资利率）与 IOER（超额准备金利率）利差扩大反映市场流动性紧张

### Dollar Liquidity 美元流动性监测
```bash
start "" "https://dollarliquidity.com/zh"
```
- 说明：全球美元流动性综合监测平台，涵盖美联储资产负债表、逆回购、TGA账户等关键流动性指标

### 融资融券余额（东方财富）
```bash
start "" "https://data.eastmoney.com/rzrq/"
```
- 说明：沪深两市融资融券余额汇总数据，反映市场整体杠杆水平和情绪

### 板块融资融券明细（东方财富）
```bash
start "" "https://data.eastmoney.com/rzrq/{plateCode}.html"
```
- example: https://data.eastmoney.com/rzrq/BK1036.html (半导体板块)
- 说明：查看特定板块的融资融券明细数据，plateCode 为东方财富板块代码

### ETF融资融券明细（东方财富）
```bash
start "" "https://data.eastmoney.com/rzrq/stock/{etfCode}.html"
```
- example: https://data.eastmoney.com/rzrq/stock/512880.html (证券ETF)
- 说明：查看特定ETF的融资融券余额及明细数据

### 港交所互联互通市场数据
```bash
start "" "https://www.hkex.com.hk/Mutual-Market/Stock-Connect/Statistics/Historical-Daily"
```
- 来源：香港交易所官方
- 说明：沪深港通历史每日统计数据，含北向资金成交明细

## 使用说明

### 股票代码格式
- **A股**：直接输入6位数字代码，如 `000001`、`600519`
- **港股**：输入代码+后缀，如 `00700.HK`
- **美股**：输入代码，如 `AAPL`、`TSLA`

### 市场后缀
- `.SH` - 上海证券交易所
- `.SZ` - 深圳证券交易所
- `.HK` - 香港交易所
- `.BJ` - 北京证券交易所

### 申万行业代码
申万行业代码为数字格式，如：
- `650100` - 航天装备Ⅱ
- `801780` - 银行Ⅱ

获取完整行业代码列表可参考 [申万宏源行业分类](https://www.swsresearch.com/institute_sw/allIndex/downloadCenter/industryType)
