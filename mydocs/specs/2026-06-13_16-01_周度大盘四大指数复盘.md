### 1.2 关键指标定义（Must Follow）
- **周涨跌幅**：
  - 公式：`（最近第五个交易日收盘价 − 基准日收盘价）÷ 基准日收盘价 × 100%`
  - 基准锚定：**最近五个交易日之前最近一个交易日的收盘价**（即第六个交易日收盘价）
  - 示例：若基准日收盘 3,000，第五日收盘 3,060 → 周涨跌幅 = +2.00%
  - 禁止：以期间第一个交易日开盘价/收盘价或其他任意交易日为基准

- **RSI（Relative Strength Index, 14日）**：
  - 取值范围：0—100
  - 超买阈值：>70（回调风险）；超卖阈值：<30（反弹机会）
  - 背离检测：价格创新高但 RSI 未创新高 → 顶背离（看空）；价格创新低但 RSI 未创新低 → 底背离（看多）
  - 报告输出：本周五 RSI 数值 + 周内 RSI 走势方向 + 是否出现背离信号

- **MACD（12/26/9）**：
  - 三要素：DIF 线（快线）、DEA 线（慢线）、柱状图（DIF−DEA）
  - 金叉：DIF 上穿 DEA → 多头信号；死叉：DIF 下穿 DEA → 空头信号
  - 零轴位置：DIF/DEA 在零轴上方为多头区域，下方为空头区域
  - 柱状图：由缩转放 = 趋势增强，由放转缩 = 趋势减弱
  - 报告输出：本周五 DIF/DEA 数值 + 周内是否发生金叉/死叉 + 柱状图趋势方向

- **均线系统（MA5/MA10/MA20/MA60）**：
  - **⚠️ 数据限制**：MA10 **仅上证指数可靠返回**，深证成指/创业板指/科创50 的 MA10 API 不单独返回
  - **替代方案**：以 MA20 或布林带中轨（=MA20）作为主要中期均线参考
  - 多头排列：MA5 > MA10 > MA20 > MA60 → 上升趋势
  - 空头排列：MA5 < MA10 < MA20 < MA60 → 下降趋势
  - 交叉信号：短期均线上穿长期均线 → 金叉（看多）；反之 → 死叉（看空）
  - 支撑/压力：价格回踩均线获支撑 = 支撑有效；反弹至均线受阻 = 压力有效
  - 报告输出：上证指数 MA5/MA10/MA20/MA60 排列 + 其余三指数 MA5/MA20/MA60 排列 + 最近的支撑/压力均线位

- **布林带（Bollinger Bands, 20日, 2σ）**：
  - **⚠️ 查询限制**：单次查询仅返回一个指数的布林带数据，四大指数**必须分 4 次查询**（见 §2.1 命令 2b~2e），无法合并
  - 上轨 = MA20 + 2×标准差；中轨 = MA20；下轨 = MA20 − 2×标准差
  - 带宽扩大 = 波动率上升；带宽收窄 = 波动率下降（可能酝酿变盘）
  - 价格位置：触及上轨 → 短期超买；触及下轨 → 短期超卖；沿上轨运行 → 强势趋势
  - 报告输出：本周五上中下轨数值 + 价格在带内相对位置（百分比） + 带宽变化趋势

- **估值对比（PE/PB 基准日 vs 最近交易日）**：
  - 对比维度：基准日（第六个交易日）PE(TTM) / PB vs 最近交易日（第五个交易日）PE(TTM) / PB
  - 变化公式：`ΔPE = PE_最近 − PE_基准`；`ΔPE% = (PE_最近 − PE_基准) ÷ PE_基准 × 100%`
  - 解读要点：
    - PE 上升 + 指数上涨 → 盈利预期驱动的估值扩张（良性）
    - PE 上升 + 指数下跌 → 盈利恶化驱动的估值被动抬升（危险）
    - PE 下降 + 指数下跌 → 杀估值（市场情绪恶化）
    - PE 下降 + 指数上涨 → 盈利增长消化估值（最健康）
  - 报告输出：四指数 PE/PB 基准值 + 最新值 + 变化量 + 变化率 + 估值-价格联动解读

- **主力资金流向**：
  - **⚠️ API 限制**：四单（超大单/大单/中单/小单）"净流入"拆解当前不可用——API 仅返回"流入"（非净）且字段不完整，尝试多次均无法获取
  - **验证可用的查询命令**：
    ```bash
    python3 .claude/skills/mx-finance-data/scripts/get_data.py \
      --query "沪深A股，YYYY-MM-DD至YYYY-MM-DD，每日超大单净流入、大单净流入、中单净流入、小单净流入、主力净流入"
    ```
    此命令返回**主力净流入合计**（全市场日度），四单净流入不会返回
  - **已验证不可用的查询**（勿重试）：
    - `"沪深A股，YYYY-MM-DD至YYYY-MM-DD，每日超大单净流入额、大单净流入额、中单净流入额、小单净流入额"` → 仅返回流入非净
    - `"沪深A股，逐日列出日期，每日超大单净流入、大单净流入、中单净流入、小单净流入"` → 返回空
  - **降级方案**：以主力净流入合计替代四单拆解
  - 主力净流入率 = 主力净流入合计 ÷ 两市成交额 × 100%
  - 全周主力净流入合计 = Σ 每日主力净流入
  - 解读（降级模式）：
    - 连续多日净流出 + 成交放量 → 主力持续减仓（偏空）
    - 净流出收窄 + 指数企稳 → 抛压减弱（可能筑底）
    - 单日大幅净流入 + 成交缩量 → 主力试探性回补（力度待确认）
  - 报告输出：每日主力净流入合计表格 + 主力净流入率 + 全周合计 + 标注"四单拆解暂不可用"
  - 数据来源：全市场（两市合计），非按指数拆分

- **融资融券（杠杆资金情绪）**：
  - 核心指标：两市融资余额（每日）、融资买入额、融资买入额占两市成交比
  - **⚠️ 数据时效**：深交所融资融券 T+1 10:00 更新；**周末查询周五数据仅得上交所单边**（约一半），需等到下周一 10:00 后数据才完整
  - **⚠️ 查询方式**：融资余额和融资买入额可能需要分多次查询才能拿到完整数据（见 §2.1 命令 3c/3d）
  - **⚠️ 异常识别**：如遇单日融资余额减半/翻倍（相对前日变化 >30%），标记为数据源未更新，剔除该日，基于可靠区间分析（本次执行中 6/12 融资数据即出现此异常）
  - 解读：
    - 融资余额持续下降 + 指数下跌 → 去杠杆驱动的下跌（偏空延续）
    - 融资余额逆势上升 + 指数下跌 → 杠杆资金抄底（偏多信号）
    - 融资余额持续上升 + 指数上涨 → 杠杆助推趋势（偏多但脆弱）
    - 融资买入占比突增 → 投机情绪升温（短期过热风险）
  - 报告输出：每日融资余额表格 + 周变动额/变动率 + 融资买入占比趋势 + 与指数涨跌联动解读 + 异常数据标注

### 2.0b 数据异常识别规则

| 异常模式 | 识别方法 | 处理 |
|:---|:---|:---|
| 融资余额单日减半/翻倍 | 与前一日对比，变化幅度 >30% | 标记为数据源未更新，剔除该日，基于可靠区间分析 |
| 主力净流入与指数涨跌严重背离 | 指数涨 >1% 但主力净流出 >1000 亿（或反之） | 标记"背离"供解读，不视为数据错误 |
| API 返回空数据 | xlsx 行数为 0 或仅有表头 | 调整 query 措辞重试 1 次；仍失败则记录为数据缺失 |

### 2.0c 查询策略（三轮递进，已收敛）

三轮顺序基于数据依赖关系：
1. **第一轮（行情基石）**→ 后续所有二次计算依赖的底层数据
2. **第二轮（技术面+估值面）**→ 独立于资金面，第一轮完成后即可推进
3. **第三轮（资金面）**→ 依赖第一轮的两市成交额（计算占比用）

### 第一轮：行情基石（3 次查询 + 1 次计算）

**目标**：获取四大指数每日量价 + 基准日收盘价 → 计算周涨跌幅

```bash

  --query "上证指数，YYYY-MM-DD至YYYY-MM-DD每日收盘价涨跌幅成交量成交额"

# 1b. 其他三大指数每日行情

  --query "深证成指、创业板指、科创50，YYYY-MM-DD至YYYY-MM-DD每日收盘价涨跌幅成交量成交额"

# 1c. 基准日（第六个交易日）收盘价
```

> **二次计算 1**：周涨跌幅 = (第五日收盘价 − 基准日收盘价) ÷ 基准日收盘价 × 100%
