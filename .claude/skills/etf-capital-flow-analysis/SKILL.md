# ETF 资金流深度分析工作流

## 1. 数据获取（妙想数据 mx-finance-data）

使用 `mx-finance-data` skill，以自然语言提交查询。单次查询建议控制在 **5-6 只 ETF**，避免返回数据量过大导致解析困难。

### 推荐查询模板

**宽基 ETF**：
```
沪深300ETF 510300、上证50ETF 510050、中证500ETF 510500、
创业板ETF 159915、科创50ETF 588000 的近一周每日净流入金额、
近一周累计流入、今日流入、当前总市值、近一周成交额、近一周涨跌幅
```

**行业 ETF**：
```
通信ETF 515880、半导体ETF 512480、医药ETF 512010、
新能源ETF 515030、券商ETF 512000 的上述同样指标
```

> 注意：妙想数据返回的是 **多 Sheet Excel 文件**，每个 ETF 的每个指标类别对应独立 Sheet。需用 pandas 解析。

## 2. 数据解析（pandas 读取 Excel）

使用 Python + pandas 读取返回的 `.xlsx` 文件：

```python
import pandas as pd
wb = pd.ExcelFile("/path/to/mx_finance_data_xxx.xlsx")
for s in wb.sheet_names:
    df = wb.parse(s)
    print(f"\n--- {s} ---")
    print(df.to_string())
```

### Sheet 结构规律
- 每只 ETF 通常包含 2-3 个 Sheet：总市值/资金流向、区间成交额/净流入、区间涨跌幅
- "总市值" Sheet 包含当日各档资金（超大单/大单/中单/小单）流入流出明细
- "区间" Sheet 包含近5日每日的区间净流入、区间主力流入流出、**净申购额估算值**

## 3. 核心分析框架

### 3.1 汇总对比表（必做）

| ETF | 市值 | 近一周涨跌幅 | 5日主力净流入 | 5日净申购额 | 关键信号 |

### 3.2 每日主力净流入明细表（必做）

按日期列出每只 ETF 的每日主力净流入，识别：
- 单日大幅流入/流出的异常日
- 连续净流入/流出的持续性

### 3.3 🔥 关键分歧识别：主力净流入 vs 净申购额

这是本分析框架的**核心洞察**。

- **主力净流入为正，净申购额为负** → "主力买、份额赎"模式
  - 含义：场内交易端有资金买入 ETF 份额，但一级市场申购赎回端是净赎回
  - 解读：**短期博弈资金为主，非长期配置资金**。机构通过 ETF 做波段，而非建仓持有。
  - 常见于：沪深300ETF、中证500ETF、上证50ETF 等大盘宽基

- **主力净流入为负，净申购额为正** → "主力卖、份额申"模式 ⚠️
  - 含义：主力资金在流出，但散户/其他资金在申购
  - 解读：**典型的拥挤度风险信号**，主力高位派发，散户追涨接盘
  - 典型案例：通信ETF 在板块涨幅第一时，主力连续净流出但净申购额大增

- **两者同向** → 信号一致，可信度高
  - 同正：资金真流入，可跟踪
  - 同负：资金真流出，需警惕

### 3.4 今日实时资金流向（如有当日数据）

对比主力流入 vs 主力流出，判断当日资金态度是否延续或逆转。

## 4. 输出模板

### 第一部分：全景汇总表
宽基 + 行业分别列表，突出涨跌幅与资金流向的背离。

### 第二部分：关键发现（3-5 条）
- 吸金王（净流入最多）
- 失血最多
- 最典型的分歧模式
- 最异常的单日波动

### 第三部分：每日明细表
日期 × ETF 的矩阵，便于追踪持续性。

### 第四部分：综合判断与可执行清单

| 优先级 | 判断 | 验证信号 |
|--------|------|---------|
| 🔴 高 | 拥堵风险确认/顶部信号 | 主力连续净流出 + 净申购为正 |
| 🟡 中 | 趋势持续/反转观察 | 净流入是否连续3日同向 |
| 🟢 低 | 板块企稳/筑底 | 等待资金回流信号 |

## 5. 常见陷阱

1. **只看净流入，不看净申购**：净流入可能仅是场内交易，不代表真实资金配置意愿
2. **忽略市值规模**：小市值 ETF（如新能源ETF 仅50亿+）的亿元级流入占比更高，弹性大但噪音也大
3. **单日数据过度解读**：需至少3-5日连续数据才能判断趋势
4. **行业ETF与宽基ETF不可直接对比**：行业ETF受板块 Beta 影响更大，宽基ETF反映市场整体情绪

## 6. 与研报交叉验证

将此资金流分析与卖方策略研报的板块配置建议交叉：
- 若研报看好某板块，但 ETF 资金流持续流出 → 质疑研报时点或动机
- 若研报警示某板块拥挤，且 ETF 出现"主力卖、份额申" → 强化警示信号
- 若研报与资金流一致 → 提高置信度
